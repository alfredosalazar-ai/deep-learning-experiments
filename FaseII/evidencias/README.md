# Evidencias - CHATBOT CIMA Fase II

Este directorio concentra los archivos que respaldan la validación técnica y funcional del prototipo desplegado.

- `capturas.pdf`: cuatro pruebas desde la interfaz web, ocho pruebas de API ejecutadas en Swagger y capturas de GitHub Actions y Render.
- `enlace_despliegue.txt`: URL pública de la aplicación y rutas de comprobación.
- `E-API-*.png`: capturas individuales de las solicitudes y respuestas de Swagger que respaldan las pruebas API-01 a API-08.

**Aplicación:** https://chatbot-cima-fase2.onrender.com/  
**Swagger:** https://chatbot-cima-fase2.onrender.com/docs  
**Health check:** https://chatbot-cima-fase2.onrender.com/health

Los resultados y limitaciones se desarrollan en `../docs/Validacion_y_Pruebas_FaseII_CHATBOT_CIMA.pdf`. El procedimiento de despliegue se encuentra en `../docs/Manual_Despliegue_Nube_CHATBOT_CIMA.pdf`.

Las consultas utilizadas son sintéticas. Las predicciones observadas se conservan tal como respondió la versión desplegada; una clasificación distinta a la intención del caso se registra como hallazgo y no se modifica para mejorar artificialmente el resultado.
